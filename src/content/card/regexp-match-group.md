- **方向**：
  - **后视（lookbehind）** 👈 `**(?<=...)**` 或 `**(?<!...)**` → **向左看**（检查左边是否匹配）
  - **前视（lookahead）** 👉 `**(?=...)**` 或 `**(?!...)**` → **向右看**（检查右边是否匹配）
- **是否匹配**：
  - **肯定（positive）** → `**=**` → 要求匹配
  - **否定（negative）** → `**!**` → 要求不匹配

| **类型** | **语法**       | **方向** | **含义**                 |
| -------- | -------------- | -------- | ------------------------ |
| 肯定后视 | `**(?<=...)**` | 👈 向左  | **左边必须**是 `**...**` |
| 否定后视 | `**(?<!...)**` | 👈 向左  | **左边不能**是 `**...**` |
| 肯定前视 | `**(?=...)**`  | 👉 向右  | **右边必须**是 `**...**` |
| 否定前视 | `**(?!...)**`  | 👉 向右  | **右边不能**是 `**...**` |
